# 🎙️ شعرینو | Poemino

### جایی که واژه‌ها جان می‌گیرند و احساسات، شعر می‌شوند.

**شعرینو** یک پلتفرم برای خلق، ویرایش، کشف و مدیریت شعر است؛ فضایی که در آن کلمات فراتر از حروف می‌روند و هر شعر، داستانی برای گفتن دارد.

شعرینو با هدف پیوند دادن هنر ادبیات و فناوری توسعه یافته است؛ پروژه‌ای که تلاش می‌کند تجربه‌ای مدرن، امن و کاربردی برای علاقه‌مندان به شعر و نویسندگی فراهم کند.

---

## ✨ دربارهٔ شعرینو

شعرینو تنها یک فضای ساده برای انتشار نوشته‌ها نیست؛ بلکه بستری برای تجربهٔ دنیای شعر، مدیریت آثار ادبی و ایجاد ارتباطی عمیق‌تر با کلمات است.

در طراحی این پروژه، توجه به تجربهٔ کاربری، ساختار نرم‌افزار، امنیت و قابلیت توسعه در کنار یکدیگر قرار گرفته‌اند تا زیرساختی مناسب برای رشد و گسترش امکانات آن فراهم شود.

## 🚀 قابلیت‌ها

- 📝 **مدیریت شعرها:** ایجاد، ویرایش و مدیریت آثار ادبی
- 🔎 **جستجو و فیلتر پیشرفته:** یافتن شعرها بر اساس معیارهای مختلف
- 📅 **فیلتر تاریخ:** جستجوی آثار بر اساس تاریخ ایجاد یا آخرین ویرایش
- 👤 **مدیریت کاربران:** ساختار اختصاصی کاربران و کنترل دسترسی‌ها
- 🔐 **احراز هویت:** سازوکارهای امنیتی برای حفاظت از حساب‌های کاربری
- 🛡️ **داشبورد مدیریتی:** مدیریت بخش‌های حساس و فرایندهای تأیید
- 📷 **تأیید هویت چهره:** استفاده از فناوری پردازش تصویر در فرایندهای احراز هویت
- 🔑 **تأیید هویت چندمرحله‌ای:** استفاده از مراحل تأیید و کد یک‌بارمصرف (OTP)
- 🔌 **رابط برنامه‌نویسی (API):** فراهم‌کردن زیرساخت ارتباط با بخش‌های مختلف سامانه
- 📚 **مستندات API:** امکان بررسی و شناخت مسیرهای ارتباطی برنامه
- ⚡ **توجه به عملکرد:** تلاش برای کاهش درخواست‌های غیرضروری پایگاه داده و بهینه‌سازی پردازش‌ها

## 🧰 فناوری‌های مورد استفاده

شعرینو با تکیه بر ابزارهای توسعهٔ نرم‌افزار و فناوری‌های وب ساخته شده است.

- **Python** — منطق اصلی برنامه
- **Django** — چارچوب اصلی توسعهٔ وب
- **Django REST Framework** — توسعهٔ API
- **SQLite / پایگاه دادهٔ پیکربندی‌شدهٔ پروژه** — ذخیره‌سازی اطلاعات
- **OpenCV** — پردازش تصویر و قابلیت‌های مرتبط با چهره
- **JWT** — سازوکار احراز هویت مبتنی بر توکن در بخش‌های مربوط
- **drf-spectacular** — تولید مستندات API

> فناوری‌های فعال و نسخه‌های دقیق آن‌ها به پیکربندی نهایی پروژه وابسته‌اند.

## 🔒 امنیت و حریم خصوصی

امنیت یکی از جنبه‌های مهم طراحی شعرینو است. ساختار دسترسی‌ها، فرایندهای تأیید هویت و کنترل بخش‌های مدیریتی با هدف محافظت از اطلاعات و جلوگیری از دسترسی غیرمجاز طراحی شده‌اند.

بااین‌حال، امنیت یک نرم‌افزار فرایندی مستمر است؛ به همین دلیل، بررسی تنظیمات محیط اجرا، مدیریت کلیدهای محرمانه، کنترل دسترسی‌ها و آزمایش مسیرهای حساس پیش از انتشار اهمیت ویژه‌ای دارد.

## 🏗️ معماری و توسعه

شعرینو بر پایهٔ Django توسعه یافته و بخش‌های مختلف آن با هدف جداسازی مسئولیت‌ها و ساده‌تر شدن نگهداری کد سازمان‌دهی شده‌اند.

توجه به ساختار ماژولار، مدیریت خطاها، کنترل دسترسی، مستندسازی و بهینه‌سازی پایگاه داده از اصول مورد توجه در توسعهٔ این پروژه است.

## 🎯 چشم‌انداز

هدف شعرینو، ساخت فضایی است که در آن فناوری در خدمت ادبیات قرار بگیرد؛ محیطی که نویسندگان بتوانند آثار خود را بهتر مدیریت کنند و تجربه‌ای دلنشین‌تر از کار با کلمات داشته باشند.
